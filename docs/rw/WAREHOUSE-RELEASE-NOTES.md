# RW warehouse — draft implementation, not production

The candidate separates warehouse item identities and stock from existing branch products. A tenant can have warehouse(s); explicit per-branch mapping links one warehouse SKU to the verified unit-only product and its dedicated STOCK: ingredient. No automatic mapping by name or rewriting legacy stock. The draft has a single-SKU dispatch per transfer; a multi-line transfer header/approval workflow is a later integration step.

Warehouse receipt credits warehouse on hand at verified acquisition cost; dispatch reduces the warehouse balance and creates in-transit stock. Partial/full branch receipt credits the canonical ingredient exactly once per request and records a linked stock movement. Cost allocated in integer satang, final receipt consumes remainder. Branch average cost is rounded to existing four-decimal convention; unknown legacy branch costs reject receipt. Internal transfers are not purchases/sales, do not change last purchase cost, and do not issue VAT or GL in this draft.

The private candidate schema revokes all privileges from client roles and service_role; no public RPC or API route. A synthetic PostgreSQL workflow checks stock conservation, replay/conflicting payloads, duplicate supplier source, role/tenant and mode denial, mapping drift, and transactional rollback. No SQL applied to CpiPOS-001.

Before production: review currency and actual supplier-document authority, IT menu + feature decisions and lifecycle in server middleware, permissions at both warehouse and destination, audit identity, multi-line transfer numbers and shortage/return/cancel policies, reconcile absolute branch stock editor and concurrent POS deductions, classify internal transfer movement and Finance inventory/in-transit journals (no revenue/COGS), full production-shaped UAT with actual migrations and test tenants, then register exact migration and expose only narrow authorized RPC. Never copy live stock to create opening warehouse balances; require actual receiving documents/count approval.
