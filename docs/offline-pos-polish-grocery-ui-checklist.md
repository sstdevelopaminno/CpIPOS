# Offline POS Polish Checklist

- UI sidebar actions are not dead buttons.
- Product and cart panels scroll independently.
- Barcode/QR input adds matched products to cart.
- Unknown barcode opens the manual product popup.
- Checkout uses a cash payment popup.
- Each confirmed checkout writes a queued offline sale.
- Offline sales list can show saved bills.
- Local bridge drawer and receipt print commands are available after checkout.
