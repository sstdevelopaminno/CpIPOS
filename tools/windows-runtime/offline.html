CpIPOS Windows Runtime

ขณะนี้เปิดหน้าเว็บ CpIPOS ไม่ได้ อาจเกิดจากอินเทอร์เน็ตหลุดหรือ DNS/Vercel เข้าไม่ได้

Windows Runtime MVP นี้ยังไม่ใช่ Offline Sales Engine เต็มรูปแบบ จึงยังไม่ควรใช้บันทึกยอดขายใหม่โดยไม่มีอินเทอร์เน็ตจนกว่าจะเพิ่ม local database และ sync queue

Local Print Bridge ยังสามารถเปิดที่ http://127.0.0.1:3210/health ได้ ถ้าโปรแกรม bridge ทำงานอยู่

เมื่ออินเทอร์เน็ตกลับมา ให้ปิดหน้านี้แล้วเปิด CpIPOS-Windows-Runtime.bat ใหม่อีกครั้ง
